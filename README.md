# Ассемблер и интерпретатор УВМ

Семестровый проект по дисциплине «Разработка кроссплатформенных программных
систем», вариант №3. Васильев С.А., ИКБО-70-23.

Проект состоит из двух программ на Python без внешних зависимостей:

- `src/assembler.py` переводит программу из CSV в машинный код УВМ;
- `src/interpreter.py` выполняет машинный код и сохраняет дамп памяти в CSV.

Общие для них форматы команд описаны в `src/isa.py`. Проект проверен на
Python 3.12.

## Язык ассемблера

Программа записывается в формате CSV. Первая строка содержит заголовок
`op,b,c`, далее каждая строка задаёт одну команду. Числа пишутся в десятичном
виде или с префиксом `0x`, пустые строки пропускаются.

| Мнемоника | A | Размер | Поле B | Поле C | Действие |
|---|---|---|---|---|---|
| `load` | 15 | 6 байт | адрес, 30 бит | константа, 10 бит | `mem[B] = C` |
| `read` | 2 | 8 байт | адрес, 30 бит | адрес, 30 бит | `mem[C] = mem[B]` |
| `write` | 9 | 8 байт | адрес, 30 бит | адрес, 30 бит | `mem[C] = mem[B]` |
| `sqrt` | 6 | 8 байт | адрес, 30 бит | адрес, 30 бит | `mem[mem[C]] = sqrt(mem[mem[B]])` |

В спецификации варианта операнд и результат команд `read` и `write` описаны
одинаково, поэтому их действие совпадает, различаются только коды.

Пример программы:

```
op,b,c
load,200,144
load,400,200
load,401,300
sqrt,400,401
```

Первая команда записывает 144 в ячейку 200, следующие две записывают адреса
операнда и результата в ячейки 400 и 401, а `sqrt` сохраняет 12 в ячейку 300.

## Ассемблер

```
python src/assembler.py ИСХОДНЫЙ.csv РЕЗУЛЬТАТ.bin [--test]
```

| Аргумент | Назначение |
|---|---|
| `ИСХОДНЫЙ.csv` | текст программы |
| `РЕЗУЛЬТАТ.bin` | двоичный файл с машинным кодом |
| `--test` | режим тестирования: вывести байты каждой команды |

Ассемблер всегда выводит число команд. Ошибка в программе сообщается с номером
строки, код завершения в этом случае равен 1.

Программа `programs/spec.csv` даёт все байтовые последовательности из
спецификации:

```
$ python src/assembler.py programs/spec.csv spec.bin --test
0x5F, 0x08, 0x00, 0x00, 0x18, 0x06
0x22, 0x1B, 0x00, 0x00, 0x90, 0x00, 0x00, 0x00
0xB9, 0x34, 0x00, 0x00, 0xDC, 0x0A, 0x00, 0x00
0xE6, 0x0B, 0x00, 0x00, 0x84, 0x09, 0x00, 0x00
Ассемблировано команд: 4
```

## Интерпретатор

```
python src/interpreter.py ПРОГРАММА.bin ДАМП.csv START-END
```

| Аргумент | Назначение |
|---|---|
| `ПРОГРАММА.bin` | двоичный файл с машинным кодом |
| `ДАМП.csv` | файл дампа со столбцами `address,value` |
| `START-END` | диапазон адресов дампа, обе границы включены |

## Модель памяти

- Память команд и данных объединена, адрес занимает 30 бит.
- Незаписанные ячейки равны нулю.
- Программа загружается с адреса 0, по одному байту в ячейку, поэтому данные
  нужно размещать за её концом.
- Команды читаются из памяти, поэтому программа может изменить свою следующую
  команду.
- Выполнение заканчивается, когда счётчик команд доходит до конца программы.
- `sqrt` вычисляет целый корень с округлением вниз.
- Константа занимает 10 бит, поэтому значения и адреса, которые программа
  записывает сама, не превышают 1023.

## Сборка и тесты

Сборка не требуется. Тесты запускаются из корня репозитория:

```
python -m unittest
```

Запуск всех примеров с выводом дампов в каталог `out`:

```
./run.sh demo
```

На Windows те же действия выполняют `.\run.bat test` и `.\run.bat demo`.
Другой интерпретатор Python можно указать в переменной окружения `PYTHON`.

## Примеры

| Программа | Что делает | Адреса дампа | Значения в дампе |
|---|---|---|---|
| `copy_array.csv` | копирует массив на другой адрес и ещё раз | 400–404 | 11, 22, 33, 44, 1023 |
| `sqrt_demo.csv` | один корень | 300 | 12 |
| `sqrt_vector.csv` | тестовая задача: корень над вектором длины 5, результат в новом векторе | 300–304 | 4, 5, 9, 12, 31 |
| `example_squares.csv` | точные квадраты | 300–304 | 1, 2, 3, 20, 31 |
| `example_rounding.csv` | значения с округлением и границы диапазона | 300–304 | 0, 1, 3, 9, 31 |
| `example_chain.csv` | корень из результата предыдущего корня | 200–204 | 256, 16, 4, 2, 1 |

Запуск тестовой задачи:

```
$ python src/assembler.py programs/sqrt_vector.csv sqrt_vector.bin
Ассемблировано команд: 20
$ python src/interpreter.py sqrt_vector.bin dump.csv 300-304
```

Содержимое `dump.csv`:

```
address,value
300,4
301,5
302,9
303,12
304,31
```
